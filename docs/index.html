Путь одного ответа сервера — от приложения до вашего экрана.

Откуда

Сервер приложения

Присылает экран целиком: товары, заказы и рекламные блоки.

Где

Shadowrocket на iPhone

Расшифровывает только адреса из списка модуля.

Что делает скрипт

Убирает рекламу

По обязательной маркировке и названиям блоков.

Куда

Приложение

Получает тот же ответ, только без рекламы.

Только на устройстве

Скрипт получает ответ сервера приложения, вырезает рекламный блок и отдаёт остальное. Третьим лицам ничего не отправляется.

Точечно

Реклама находится по обязательной маркировке, а рекомендации — по названиям блоков. Ответ без рекламы не меняется вовсе.

Аккуратно

Расшифровываются только адреса из списка модуля. Банки, Госуслуги и мессенджеры в него не входят.

Три шага и пара минут.

Нужен iPhone с установленным Shadowrocket.

  1. Включите расшифровку HTTPS

    1. Вкладка с конфигами → ⓘ справа от вашего конфига.
    2. «Расшифровка HTTPS» → «Сертификат»: сгенерируйте и установите новый CA-сертификат.
    3. Настройки iOS → Основные → VPN и управление устройством → установите профиль.
    4. Настройки iOS → Основные → Об этом устройстве → Доверие сертификатам → включите.
    5. Вернитесь в Shadowrocket и включите «Расшифровку HTTPS» в том же конфиге.

  2. Добавьте модуль

    Вкладка с конфигами → «Модули» → ＋ → вставьте ссылку и проверьте, что модуль включён.

    https://raw.githubusercontent.com/Melidovskiy/ru-apps-adblock/main/RU-Apps-AdBlock.sgmodule

  3. Перезапустите приложения

    Смахните их из списка открытых и откройте снова. Часть правил Wildberries применяется со следующего запуска.

Сертификат — ваш ключ

Не делитесь экспортом конфигурации Shadowrocket: в нём может быть сертификат с закрытым ключом.

Если что-то сломалось

Выключите модуль и перезапустите приложение. Помогло — сообщите о проблеме.

Плашки «Включён VPN»

Их рисуют сами приложения (Госуслуги, банки), модуль их не уберёт.

Обновления приложений

После обновления что-то может снова появиться, пока правила не обновят. Модуль обновляется по той же ссылке.

RU Apps AdBlock GitHub · MIT

Независимый проект, не связан с перечисленными сервисами. Названия и товарные знаки принадлежат их правообладателям и используются только для указания совместимости. Фильтрация выполняется на устройстве пользователя и не изменяет данные на серверах сервисов. Телефон на главной — иллюстрация.

Проект предоставляется «как есть». Использование Shadowrocket, расшифровки HTTPS и сторонних модулей может регулироваться условиями соответствующих сервисов; пользователь сам отвечает за их соблюдение.
