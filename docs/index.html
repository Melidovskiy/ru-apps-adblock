Как это работаетHow it works

Всё на телефоне.
Ничего лишнего.All on your phone.
Nothing more.

Только на устройствеOn the device only

Скрипт получает ответ сервера приложения, вырезает рекламный блок и отдаёт остальное. Третьим лицам ничего не отправляется.The script takes the app's server response, cuts the ad block out and passes on the rest. Nothing goes to third parties.

ТочечноPrecise

Реклама находится по обязательной маркировке, а рекомендации — по названиям блоков. Ответ без рекламы не меняется вовсе.Ads are found by their legally required marking, recommendations by block names. A response without ads isn't touched at all.

АккуратноCareful

Расшифровываются только адреса из списка модуля. Банки, Госуслуги и мессенджеры в него не входят.Only the addresses in the module's list are decrypted. Banks, Gosuslugi and messengers aren't on it.

УстановкаInstall

Три шага
и пара минут.Three steps,
a couple of minutes.

Нужен iPhone с установленным Shadowrocket.You'll need an iPhone with Shadowrocket installed.

Включите расшифровку HTTPSTurn on HTTPS decryption

  1. Вкладка с конфигами → ⓘ справа от вашего конфига.
  2. «Расшифровка HTTPS» → «Сертификат»: сгенерируйте и установите новый CA-сертификат.
  3. Настройки iOS → Основные → VPN и управление устройством → установите профиль.
  4. Настройки iOS → Основные → Об этом устройстве → Доверие сертификатам → включите.
  5. Вернитесь в Shadowrocket и включите «Расшифровку HTTPS» в том же конфиге.
  1. Config tab → ⓘ next to your config.
  2. HTTPS Decryption → Certificate: generate and install a new CA certificate.
  3. iOS Settings → General → VPN & Device Management → install the profile.
  4. iOS Settings → General → About → Certificate Trust Settings → turn it on.
  5. Back in Shadowrocket, turn on HTTPS Decryption in the same config.

Добавьте модульAdd the module

Вкладка с конфигами → «Модули» → ＋ → вставьте ссылку и проверьте, что модуль включён.Config tab → Modules → ＋ → paste the link and make sure the module is on.

https://raw.githubusercontent.com/Melidovskiy/ru-apps-adblock/main/RU-Apps-AdBlock.sgmodule

Перезапустите приложенияRestart the apps

Смахните их из списка открытых и откройте снова. Часть правил Wildberries применяется со следующего запуска.Swipe them out of the app switcher and open them again. Some Wildberries rules apply from the next launch.

Сертификат — ваш ключThe certificate is your key

Не делитесь экспортом конфигурации Shadowrocket: в нём может быть сертификат с закрытым ключом.Don't share a Shadowrocket config export: it may contain the certificate with its private key.

Если что-то сломалосьIf something breaks

Выключите модуль и перезапустите приложение. Помогло — сообщите о проблеме.Turn the module off and restart the app. If that helps, report it.

Плашки «Включён VPN»«VPN is on» notices

Их рисуют сами приложения (Госуслуги, банки), модуль их не уберёт.The apps draw them themselves (Gosuslugi, banks); the module can't remove them.

Обновления приложенийApp updates

После обновления что-то может снова появиться, пока правила не обновят. Модуль обновляется по той же ссылке.After an app update something may come back until the rules catch up. The module updates from the same link.
